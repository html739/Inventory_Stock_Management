# Inventory & Stock Management System

## Project Overview
The Inventory & Stock Management System is a database-based project developed using Oracle SQL and PL/SQL. It helps manage product details, monitor stock availability, update inventory records, and identify products with low stock.

The project uses a frontend interface to make inventory management easier and more user-friendly.

## Objectives
- To maintain product and stock details.
- To monitor available inventory.
- To identify products with low stock.
- To update stock quantities efficiently.
- To generate inventory reports.
- To understand the practical use of Oracle SQL and PL/SQL.

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python
- **Database:** Oracle Database
- **Database Programming:** SQL and PL/SQL
- **Development Tool:** Visual Studio Code

## Key Features
- Product and inventory management.
- Stock quantity tracking.

## How to Run the Project
1. Download or clone the project repository.
2. Open the project folder in Visual Studio Code.
3. Configure the Oracle Database connection in the backend.
4. Make sure the required Python packages are installed.
5. Run the backend Python file.
6. Open the frontend in your browser or follow the project's configured frontend setup.
7. Use the interface to manage inventory records.
